# Portfolio de Xavi Martínez

Portfolio estático con HTML, CSS y JavaScript, preparado para GitHub Pages.

Abre `index.html` en el navegador para ver el sitio. También puedes servir esta carpeta con cualquier servidor HTTP estático.

Edita los proyectos en `FEATURED_PROJECTS`, dentro de `index.html`. La experiencia, formación y contacto están en las secciones del HTML. Los estilos activos están en `css/redesign.css` y la fotografía y currículums en `public/`.

El CV español incluye un espacio antes de `.pdf`; su enlace utiliza `%20`. El diseño se adapta a móviles, incluye navegación accesible y habilidades agrupadas por categorías, y respeta la preferencia de movimiento reducido. Los proyectos se muestran sin depender de la API de GitHub.
